Es un proyecto desarrollado para empresas españolas. La documentación estará en español (es-ES)

Este proyecto pretende cubrir las necesidades de gestión técnica de pequeños clubs de fútbol.
Su ámbito será la gestión manual de estadísticas de sus distintos equipos de las distintas categorías (desde pre-benjamín a senior, varios equipos en cada categoría).

Para ello se han de construir una serie de artefactos:
- Base de datos
- API backend
- Web backoffice
- App iOS de consulta
- App Android de consulta

También se ha de contratar servicios de cloud para el alojamiento de los 3 primeros artefactos.

Para su desarrollo se contará con mi participación como único desarrollador y obviamente con la ayuda de Claude Code.
